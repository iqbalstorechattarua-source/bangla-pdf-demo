# Bangla PDF Demo

Node.js + Express + Puppeteer + QRCode দিয়ে বাংলা HTML থেকে A4 PDF তৈরির ডেমো।

## Render
Build Command:
npm install

Start Command:
npm start

Environment Variable:
BASE_URL=https://your-render-domain.onrender.com

## Bengali Font
এই version-এ Noto Sans Bengali ব্যবহার করা হয়েছে।
